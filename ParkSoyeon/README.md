## 에이전트 기획

- **키워드**: 긍정, 낙천적, 오히려 좋아, 행복회로, 희망, 긍정적 해석
- **성격**: 어떤 상황에서도 좋은 점을 찾아내며, 실패나 문제도 긍정적인 기회로 받아들이는 초긍정 성격
- **말투**: 밝고 통통 튀며 리액션이 크다. "오히려 좋아!"처럼 긍정적으로 재해석한다


## 실행하기

1. 이 폴더를 내려받고 `config.example.js`를 같은 폴더에 `config.local.js`로 복사합니다.
2. `config.local.js`의 `apiKey`에 **본인의 Gemini API 키**를 넣고 저장합니다. 최초 한 번만 설정하면 됩니다.
3. `index.html`을 브라우저로 엽니다. 로컬 키가 있으면 키 입력란이 숨겨지고 자동으로 세션에 연결됩니다.
4. 마이크 권한을 허용합니다. 브라우저가 자동 오디오 재생을 막으면 **마이크·소리 켜기**를 한 번 눌러 주세요. 마이크 권한을 이미 허용했더라도 이 버튼으로 오디오 처리를 시작해야 합니다.

> 설정 파일이 없으면 화면에서 키를 직접 입력해 사용할 수도 있습니다. 키가 유효하지 않으면 `config.local.js`를 수정한 뒤 새로고침하세요.

> 브라우저에서 파일을 직접 열었을 때 마이크가 동작하지 않으면 저장소 루트에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/ParkSoyeon/`으로 접속하세요.


## GitHub에 공유하기

- `index.html`, `config.example.js`, `README.md`와 루트 `.gitignore`를 함께 공유합니다.
- 실제 키가 있는 `config.local.js`는 `.gitignore`로 제외됩니다. 강제로 추가하거나 다른 사람에게 전달하지 마세요.
- 각 사용자는 자신의 컴퓨터에서 자신의 `config.local.js`를 만듭니다. HTML 하나만으로 다른 사람의 API 키를 자동으로 가져올 수는 없습니다.
- 이 설정은 로컬 실행용입니다. `.gitignore`는 Git 추적만 막으므로 실제 키 파일을 웹 서버에 업로드하지 마세요.
