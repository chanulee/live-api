# sunny · Gemini Live Voice Agent

인터융합2 1주차 과제. 맥 브라우저에서 마이크로 말하면 Gemini가 음성으로 답하고,
말을 끊으면 재생이 즉시 멈추는 음성 에이전트.

## 실행

이 폴더(`sunny/`)에서:

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 연다.

`index.html` 을 더블클릭해서 `file://` 로 열면 **마이크와 AudioWorklet이 동작하지 않는다.**
반드시 로컬 서버로 띄운다.

### 키 넣기

```bash
cp key.example.js key.js
```

`key.js` 를 열어 `window.GEMINI_KEY` 에 키를 넣는다.
키는 [Google AI Studio](https://aistudio.google.com/api-keys) 에서 발급한다 (free tier).

**`app.js` 에는 절대 쓰지 않는다.** `key.js` 는 `.gitignore` 에 있어서 커밋 자체가 되지 않는다.

## 성격

> 유머러스하고 살짝 자조적이고, 말투는 철학적이지만 무겁거나 진지하지는 않음

형용사만 프롬프트에 넣으면 음성에서는 무너진다. 문장이 길어지고, 자조가 매 턴 반복돼
우울해 보이고, 유머는 아재개그로 빠진다. 그래서 `app.js` 의 `SYSTEM_INSTRUCTION` 에서
아래 규칙으로 풀어서 준다.

| 항목 | 규칙 | 이유 |
| --- | --- | --- |
| 턴 길이 | 두 문장 이내 | 음성은 길면 상대가 기다리다 끼어든다 |
| 자조 빈도 | 세 번에 한 번 | 매 턴 하면 성격이 아니라 우울로 들린다 |
| 자조 대상 | 처지·몸·기억 (능력·존재 가치 ❌) | 불쌍해 보이면 실패 |
| 철학 | 일상어로. 전문 용어 금지 | "무겁지 않음"이 여기서 갈린다 |
| 유머 | 큰 얘기 → 민망해하는 낙차 | "웃기게 말해"는 아재개그를 부른다 |
| 금지 | 사과, 조언, 이모지, 목록 | 소리로 나가는 말이다 |

목소리는 기본 `Charon` (낮고 건조함). 화면에서 바꾸고 **이 목소리 듣기**로 바로 비교할 수 있다.
같은 대사도 목소리 톤 하나로 "위트"가 되거나 "진짜 우울한 기계"가 되므로 직접 들어보고 고른다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면. 버튼, 목소리 선택, 레벨 미터, 자막, 로그 |
| `app.js` | WebSocket 세션, 마이크 전송, 재생 큐, 끼어들기, 성격 프롬프트 |
| `pcm-recorder.js` | AudioWorklet. Float32 → 16-bit PCM, 64ms 프레임 |
| `key.example.js` | 키 템플릿 (커밋함) |
| `key.js` | 실제 키 (**커밋 안 함**) |

## 작동 방식

1. 로컬 페이지를 연다.
2. Live 세션을 연다. (`responseModalities: ["AUDIO"]`)
3. 마이크 소리를 계속 API로 보낸다. (16kHz PCM, 마이크는 끄지 않는다)
4. 돌아온 목소리를 같은 페이지의 스피커로 재생한다. (24kHz)
5. 사용자가 끼어들면 재생 큐를 즉시 비운다.
6. 3–5를 반복한다.

### 기술 메모

- **AudioContext를 두 개 쓴다.** 입력 16000Hz, 출력 24000Hz.
  입력 컨텍스트를 16k로 열면 워크렛에 들어오는 샘플이 이미 16kHz라 리샘플링 코드가 필요 없다.
  출력은 Live API가 돌려주는 규격이 24k라서, 16k로 재생하면 목소리가 느려지고 낮아진다.
- **AEC는 브라우저에 맡긴다.** `getUserMedia` 의 `echoCancellation: true`.
  마이크 입력과 스피커 재생이 같은 페이지에서 일어나야 작동한다.
  라즈베리파이로 옮겨도 이 구조가 그대로 방어선이 된다.
- **끼어들기는 두 군데서 판정한다.** 서버의 `serverContent.interrupted` 가 정본이지만
  한 박자 늦어서, 로컬 RMS 임계값으로 먼저 끊는다. 감도는 화면 슬라이더로 조절한다.
- **끊은 뒤에도 오디오가 계속 도착한다.** 그래서 큐를 비운 다음 일정 시간(3초) 동안
  도착하는 조각을 버리는 `suppress` 구간이 있다. 이게 없으면 끊었는데 계속 말하는 것처럼 들린다.
